EnglishConnect Site Plan

Site name

English Connect 2. I selected this name because is the name of the official course of the Church of Jesus Chrsit. I want to use this courses as an example because I'm teaching English on mondays and I could see the blessing that comes with this course.

Site purpose

The site is going to provide information about English language courses and allow students to register.

Scenarios

  • How can I register for an EnglishConnect course?
  • Where and when are the classes held?
  • What English level do I need to join the course?

Color scheme

Dark Blue (#003366) for headings and navigation.

Light Gray (#F5F5F5) for backgrounds.

Typography

Poppins for headings.

Arial for body text.
